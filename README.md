## 📖 О проекте

**TeleWEB** — системный модуль для Android, перехватывающий TCP-трафик официальных и сторонних клиентов Telegram и прозрачно инкапсулирующий его в зашифрованные WebSocket-сессии (WSS). Модуль устраняет блокировки дата-центров Telegram со стороны интернет-провайдеров и мобильных операторов (DPI), не требуя ручной настройки SOCKS5/MTProto-прокси в самом приложении и не создавая ресурсоёмких виртуальных VPN-интерфейсов (`tun0`).

### Поддерживаемые клиенты
Официальный **Telegram**, **Telegram X**, **Exteragram**, **Nekogram**, **Forkgram**, **Cherrygram**, **Ayugram**, **MDGram**, **Swiftgram** и любые другие клиенты на базе официального TDLib.

## ⚡ Ключевые функции и возможности

### 1. Прозрачный перехват без VPN (Transparent Redirection)
- **Нулевой оверхед на батарею**: Перенаправление выполняется ядром Linux через `iptables nat REDIRECT` только для UID обнаруженных клиентов Telegram на локальный порт `17841`.
- **Совместимость с VPN**: Не создает сетевого интерфейса `tun0`, благодаря чему может работать одновременно с любыми VPN-сервисами (V2Ray, Clash, AdGuard, WireGuard).
- **Точные диапазоны адресов Telegram**:
  - `149.154.160.0/20`, `149.154.164.0/22`, `149.154.168.0/22`, `149.154.172.0/22`
  - `91.108.4.0/22`, `91.108.8.0/22`, `91.108.12.0/22`, `91.108.16.0/22`, `91.108.20.0/22`, `91.108.56.0/22`
  - `185.76.151.0/24`, `91.105.192.0/23` (CDN203)

### 2. Глубокий разбор протокола MTProto (Obfuscated2 Framing)
- **Точное определение DC и медиа**: Модуль считывает первые 64 байта рукопожатия Obfuscated2 (`init[0:64]`), безошибочно извлекая знаковый номер дата-центра (`DC1`–`DC5`) и признак медиа-потока.
- **Корректный бинарный фрейминг**: Каждый MTProto-пакет отправляется отдельным бинарным WebSocket-кадром (`opcode 2`). Исключены разрывы соединений из-за произвольной буферизации TCP-потока.
- **Поддержка Quick ACK**: Полная обработка Abridged MTProto маркеров (`0x80–0xFE` и `0xFF`), устраняющая ошибки `invalid abridged length marker` при отправке сообщений.

### 3. Четырёхуровневая маршрутизация (Multi-Tier Ingress Routing)
1. **Tier 1: Прямой KWS WSS (`kwsN.web.telegram.org:443`)**:
   Прямое подключение к нативной инфраструктуре веб-шлюзов Telegram.
2. **Tier 2: Cloudflare Domain Fronting**:
   Автоматический обход через WSS на Cloudflare-доменах (`kwsN.<domain>`) при блокировке прямых IP Telegram.
3. **Tier 3: Выделенный Cloudflare Worker Gateway**:
   Поддержка собственного шлюза Cloudflare Worker на базе `cloudflare:sockets` с шифрованием uTLS (Chrome ClientHello) для обхода жестких DPI-фильтров.
4. **Tier 4: CDN203 Raw TCP Pass-Through**:
   Выделенный низколатентный туннель для кэширующих медиа-серверов Telegram CDN203 (`91.105.192.100:443`).

### 4. Happy Eyeballs v2 Connection Racing
- Конкурентный запуск параллельных соединений (Direct vs Cloudflare vs Worker) со сдвигом в 250 мс. Модуль выбирает маршрут с наименьшей задержкой рукопожатия, обеспечивая мгновенный отклик при открытии диалогов.
- Опциональная балансировка (`CF Balance`) для равномерного распределения нагрузки по пулу доменов.

### 5. Динамическая защита от сбоев и Cooldown-менеджмент
- **Детекция сбоев**: Автоматическое временное исключение маршрутов на 3 минуты при получении HTTP 429 (Rate Limit), 403 (Forbidden), 502/503/504 или повторных ранних удалённых EOF.
- **Персистентный кэш маршрутов (`route-cache.json`)**: Быстрые проверенные маршруты сохраняются на диск вне каталога модуля. При перезапуске устройства соединение восстанавливается мгновенно, без задержек на сканирование сети.
- **Фоновое автообновление доменов**: Встроенный периодический загрузчик свежих Cloudflare-доменов из сети с проверкой целостности.

### 6. Zero-Allocation I/O архитектура
- Использование пулов `sync.Pool` (`ioBufPool`, `frameBufPool`) для всех операций ввода-вывода — нулевое выделение динамической памяти в «горячем пути» и минимальная нагрузка на сборщик мусора Go.
- Тонкая настройка сокетов: `TCP_NODELAY`, агрессивные системные буферы приёма/передачи (256 КБ), системный TCP KeepAlive (30с) и 5-минутный Idle Watchdog для очистки зависших дескрипторов.

### 7. Системный Watchdog и Anti-Freeze защита
- **Защита процесса**: Демону присваивается максимальный приоритет OOM (`oom_score_adj = -1000`).
- **Разморозка клиентов Telegram (Cgroup Unfreezer)**: Периодический вывод фоновых процессов Telegram из `cgroup freezer` в корневую группу, что предотвращает пропуск сообщений при агрессивных механизмах Doze / OEM App Standby без разряда аккумулятора.
- **Supervisor-петля**: Фоновый скрипт `service.sh` отслеживает состояние службы каждые 60 секунд, автоматически восстанавливая правила iptables и демон при переключении Wi-Fi ↔ LTE.

### 8. Автономный Material 3 WebUI
- **100% Zero-CDN**: Полная независимость от внешнего интернета; весь UI, шрифты, векторные SVG-иконки и логика скомпонованы в один локальный файл.
- **Material You Monet**: Динамический расчёт темы на основе алгоритма цветовой науки Google M3 (Tone Mapping) с возможностью выбора любого акцентного цвета через интерактивный цветовой круг или готовые палитры.
- **AMOLED Режим**: Настоящий чистый черный цвет (`#000000`) для максимальной экономии энергии на OLED/AMOLED дисплеях.
- **Жестовая система (из `nfqws2-android`)**:
  - Полная поддержка системного жеста Android «Назад» (`backInterceptor: javascript`, `onBackKeyPressed`, история слоев Chromium).
  - Свайп-закрытие шторки настроек вниз с физическим сопротивлением и 120 FPS трекингом.
  - Горизонтальный свайп контента для переключения между вкладками с отсечением ложных вертикальных скроллов.
  - Автоматическое скрытие нижней панели навигации при открытии виртуальной клавиатуры (`body.kb-open`).
- **Англоязычное системное логирование**: Журнал событий оформлен исключительно в лаконичных англоязычных терминах для удобного аудита и экспорта.

## 🛠 Управление через CLI

Модуль предоставляет удобный интерфейс командной строки:

```bash
# Проверка текущего статуса службы и статистики
/data/adb/modules/teleweb/bin/tgws status

# Запуск службы перехвата (правила iptables + демон + watchdog)
/data/adb/modules/teleweb/bin/tgws boot

# Остановка перехвата и очистка правил iptables
/data/adb/modules/teleweb/bin/tgws stop

# Проверка работоспособности и автоматическое восстановление (supervisor)
/data/adb/modules/teleweb/bin/tgws ensure

# Тестирование парсеров и внутренних инвариантов
/data/adb/modules/teleweb/bin/tgws check
```

## 🌐 Настройка собственного Cloudflare Worker Gateway

Для максимальной стабильности и гарантированного обхода глубоких блокировок вы можете развернуть собственный шлюз в Cloudflare Workers:

1. Откройте панель Cloudflare Dashboard ➔ **Workers & Pages** ➔ **Create Worker**.
2. Вставьте код из файла [`worker/cloudflare-worker.js`](file:///d:/tgopen/worker/cloudflare-worker.js).
3. Нажмите **Deploy**.
4. Скопируйте полученный домен (например, `my-tg-gateway.user.workers.dev`).
5. В WebUI TeleWEB откройте вкладку **«Маршрутизация»**, вставьте адрес воркера в поле **«Кастомный Cloudflare Worker»** и сохраните настройки.
